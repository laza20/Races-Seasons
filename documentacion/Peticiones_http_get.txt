peticiones_http_get.view_data_charge()
======================================
LLamada         -> /Datos/Cargas/{base_de_datos}
Ejemplo Llamada -> Circuitos/Datos/Cargas/Pilotos

Esta funcion nos permite verificar los datos que son necesarios para realizar las cargas en las diversas tablas. Para su correcto funcionamiento precisamos:
router          : Necesario para la llamada.
schema          : Necesario para devolver los datos al usuario una vez guardados.
Clase           : Permitira que la obtencion de los datos json tengan un formato determinado.
base_de_datos_2 : Solo necesario para bases de datos de temporada, por ejemplo pilotos_por_temporada, ya que los que nos permite es
buscar los datos restantes de este que no se encuentran guardados como tal. Permite por medio de su distincion encontrar los datos
en esta segunda base de datos.
campo           : Este cumplira la funcion de campo que sera modificado por el dato que se trae de la base de datos 2. (con el proposito de mostrar un campo mas comprensible para el usuario)
campo2          : Cumple la funcion de busqueda del campo que luego reemplazara al campo normal.
